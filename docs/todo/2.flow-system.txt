Konteks project:
- Go
- module: github.com/niamfauzi/go-starter
- package-based structure
- memakai struktur versi siap berkembang:
  - internal/modules/
  - internal/platform/
  - internal/shared/
- menggunakan:
  - chi
  - GORM

  - JWT
  - middleware

  - SQL migration manual
  - seeder

Tujuan:
Saya ingin memahami **alur kerja ketika request masuk** secara utuh, khususnya untuk endpoint:

`POST /api/v1/products`

Saya ingin kamu menjelaskan alurnya dengan sangat ramah untuk pemula, seolah-olah sedang mengajari saya membaca project nyata.

Tolong jelaskan alur lengkap request **Create Product** dari awal sampai akhir, misalnya:
1. request masuk ke HTTP server
2. router mencocokkan endpoint
3. middleware dijalankan satu per satu
4. tenant diambil dari header `X-Tenant-Id`
5. JWT dibaca dari header `Authorization`
6. request body di-parse
7. request di-validasi
8. handler memanggil service
9. service menjalankan business logic
10. service/repository menyimpan data ke MySQL lewat GORM
11. cache Redis dihapus / diperbarui bila perlu
12. response sukses dikembalikan
13. jika error, bagaimana alurnya sampai response error keluar
14. logging terjadi di bagian mana saja

Yang saya inginkan:
- jelaskan **step by step**
- jelaskan **file mana yang terlibat**
- jelaskan **fungsi tiap layer**
- jelaskan **data berpindah dari mana ke mana**
- jelaskan **kenapa urutannya seperti itu**
- jelaskan **apa yang terjadi kalau salah satu step gagal**
