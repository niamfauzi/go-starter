# Dokumen Sesi Belajar — go-starter

Dokumen ini memecah starter project `github.com/niamfauzi/go-starter` menjadi 10 sesi belajar yang mudah diikuti pemula.

## Cara memakai dokumen ini

Urutan paling enak:

1. Baca **Sesi 1** untuk memahami bentuk project secara keseluruhan.
2. Lanjut **Sesi 2** untuk menyiapkan environment, database, migration, dan seeder.
3. Masuk ke **Sesi 3** dan **Sesi 4** untuk memahami auth dan CRUD.
4. Setelah itu baru masuk ke concern lintas fitur seperti middleware, logging, cache, dan error handling.
5. Tutup dengan **Sesi 9** dan **Sesi 10** supaya kamu tahu cara test dan cara menambah fitur baru.

10. `10-sesi-10-cara-menambah-fitur-baru.md`

## Saran ritme belajar

- 1 sesi = 1 kali belajar.
- Setelah membaca satu sesi, jalankan langkah praktiknya.
- Jangan langsung baca semua dokumen sekaligus.
- Kalau ada bagian yang terasa berat, kembali ke file project yang disebut di sesi itu.
